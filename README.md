# Proyecto-sprint-7

Esta aplicación web fue desarrollada con Streamlit para explorar un conjunto de datos de anuncios de vehículos usados.

La aplicación permite visualizar:
- La distribución del odómetro mediante un histograma.
- La relación entre odómetro y precio mediante un gráfico de dispersión.

El objetivo es practicar el desarrollo de una aplicación web interactiva conectada a un conjunto de datos real usando pandas, Plotly y Streamlit.
